# 映射与命中协议

> **状态**: 草稿  
> **版本**: 1.0.0-alpha

## 概述

本文档定义了用于报告覆盖率映射和命中的 API 协议。它描述了载荷结构、必需字段和行为语义。

## 协议原则

1. **分离**: 映射和命中是独立的端点
2. **故障开放**: 命中报告绝不能阻塞执行
3. **幂等性**: 映射报告是幂等的
4. **最小化**: 命中载荷是最小的（无业务上下文）

## 映射端点

### POST /api/coverage/map

报告覆盖率映射结构（构建时）。

**时机**: CI/CD 构建阶段

**认证**: 必填（CI 令牌）

**幂等性**: 是（相同的 mapHash 可以多次报告）

### 请求载荷

```typescript
{
  // 构建上下文（必需）
  provider: string;           // "gitlab", "github"
  repoID: string;             // 仓库标识符
  commitSha: string;          // Git 提交 SHA
  buildTarget: string;        // "web", "ios", "android"
  
  // 可选的构建上下文
  pipelineId?: string;
  buildId?: string;
  buildHash?: string;         // 可选: 构建身份哈希
  
  // 插件元数据（必需）
  pluginVersion: string;      // "1.0.0"
  schemaVersion: number;      // 2
  
  // 场景上下文（可选）
  sceneKey?: string;
  tags?: Record<string, string>;
  
  // 映射（文件映射数组）
  maps: Array<{
    mapHash: string;          // 必填: 结构身份
    filePath: string;          // 相对文件路径
    fileContentHash?: string; // 可选: 源内容哈希
    coverageMap: {            // 兼容 Istanbul 的结构
      s: Record<string, StatementMap>;
      f: Record<string, FunctionMap>;
      b: Record<string, BranchMap>;
    };
    sourceMap?: string;       // 可选: base64 源映射
  }>;
}
```

### 响应

```typescript
{
  success: boolean;
  mapCount: number;           // 处理的映射数量
  errors?: Array<{
    mapHash: string;
    error: string;
  }>;
}
```

### 行为

- 具有相同 `mapHash` 的映射会被去重
- 缺失的 `mapHash` 会在服务器端计算（不推荐）
- 无效的映射会被拒绝并返回错误详情

## 命中端点

### POST /api/coverage/hit

报告覆盖率执行数据（运行时）。

**时机**: 测试执行或运行时

**认证**: 可选（公共端点）

**幂等性**: 否（命中是累加的）

**故障开放**: 绝不能抛出异常或阻塞

### 请求载荷

```typescript
{
  // 身份（必需）
  mapHash: string;           // 必填: 结构身份
  
  // 可选身份
  buildHash?: string;         // 可选: 构建身份
  sceneKey?: string;          // 可选: 执行上下文
  
  // 执行数据（必需）
  hits: {
    s?: Record<string, number>;  // 语句命中
    f?: Record<string, number>;  // 函数命中
    b?: Record<string, [number, number]>; // 分支命中
  };
  
  // 元数据
  ts?: number;                // 时间戳（Unix 时间戳）
}
```

### 响应

```typescript
{
  success: boolean;
  // 无详细错误信息（故障开放）
}
```

### 行为

- **故障开放**: 无效的命中会被静默丢弃
- **异步**: 立即返回响应，处理是异步的
- **无验证**: 服务器不验证 `mapHash` 的存在（异步查找）

## 字段语义

### mapHash

- **必需**: 是（在两个端点中）
- **用途**: 将命中链接到映射结构
- **格式**: 十六进制字符串（SHA-256）
- **计算**: 客户端（推荐）或服务器端（备选）

### sceneKey

- **必需**: 否
- **用途**: 执行上下文签名
- **格式**: 十六进制字符串（场景字段的哈希）
- **计算**: 客户端从标准化的场景字段计算

### tags

- **必需**: 否
- **用途**: 过滤和聚合维度
- **格式**: 键值映射
- **注意**: 不是合并身份的一部分

## 版本控制

### 协议版本

包含在头部或载荷中：

```
X-Canyon-Protocol-Version: 1.0
```

### 向后兼容性

- 新的可选字段：始终接受
- 移除的字段：已废弃，然后在下一个主要版本中移除
- 必需字段：不能移除

## 错误处理

### 映射端点

- **400**: 无效的载荷结构
- **401**: 需要认证
- **500**: 服务器错误（建议重试）

### 命中端点

- **200**: 始终返回（故障开放）
- 错误记录在服务器端，不返回给客户端

## 安全考虑

### 映射端点

- 需要认证（CI 令牌）
- 速率限制：适度（每个构建）
- 载荷大小：大（映射可以是 MB 级别）

### 命中端点

- 公共端点（不需要认证）
- 速率限制：严格（每个 IP）
- 载荷大小：小（命中是 KB 级别）
- 哈希白名单：只接受已知的 mapHashes（可选）
