# **变更代码覆盖率**

**变更代码覆盖率**允许您专注于变更代码的测试覆盖情况。

## 维度


### **新（文件）行覆盖率**

**计算逻辑：**
1. 两个提交之间的 git diff => 变更文件 => 变更行号（可能包含注释和空行）
2. 遍历变更文件的**coverageMap**，检查**branchMap**、**fnMap**和**statementMap**的位置是否包含变更行号
3. **覆盖**定义：变更行号所在的**branchMap**、**fnMap**和**statementMap**都被覆盖

**计算公式：**


```
新（文件）行覆盖率 = 覆盖的（文件）行数 / 总新（文件）行数
```
