# Canyon 工具链兼容性

本文档描述了 Canyon 工具链组件的兼容性要求。

## 工具要求

| 工具 | Node.js 要求 | 描述 |
|------|---------------------|-------------|
| `canyon-cli` | Node.js >= 16 | 用于上传覆盖率数据的命令行工具 |
| `babel-plugin-canyon` | Node.js >= 16 | 用于代码插桩的 Babel 插件 |
| `swc-plugin-canyon` | Node.js >= 16 | 用于代码插桩的 SWC 插件 |

## 插桩输出

Canyon 插件生成的插桩代码具有以下特点：

- **JavaScript 语法**: ES5（兼容所有现代浏览器和 Node.js）
- **运行时支持**: 
  - 浏览器 (Chrome, Firefox, Safari, Edge)
  - Node.js
  - React Native

## 构建工具兼容性

Canyon 插件与以下构建工具兼容：

- **Babel**: 通过 `babel-plugin-canyon` 提供完全支持
- **SWC**: 通过 `swc-plugin-canyon` 提供完全支持
- **Webpack**: 兼容（通过 Babel 或 SWC）
- **Vite**: 兼容（通过 Babel 或 SWC）
- **Next.js**: 兼容（通过 Babel 或 SWC）
- **React Native**: 兼容（通过 Babel）

## CI/CD 兼容性

Canyon 自动检测并适配以下 CI/CD 提供商：

- **GitLab CI**: 完全支持
- **GitHub Actions**: 完全支持
- **其他 CI 提供商**: 可手动配置

## 浏览器兼容性

插桩代码和覆盖率收集脚本与以下浏览器兼容：

- Chrome/Chromium 90+
- Firefox 88+
- Safari 14+
- Edge 90+

## Node.js 兼容性

- Node.js 16.x (LTS)
- Node.js 18.x (LTS)
- Node.js 20.x (LTS)
- Node.js 22.x (Current)
