# 快速开始

如何将 Canyon 插件安装到您的应用程序中。

> [!NOTE]
>
> 目前仅支持 Babel 插件。SWC、Vite 和其他插件仍在开发中。[插件](https://github.com/canyon-project/canyon/tree/main/plugins)。

## Canyon 工具链兼容性

### 工具

| 工具 | Node.js 要求 |
|------|---------------------|
| `canyon-cli` | Node.js >= 16 |
| `babel-plugin-canyon` | Node.js >= 16 |
| `swc-plugin-canyon` | Node.js >= 16 |

### 插桩输出

- **JavaScript 语法**: ES5
- **运行时**: Browser / Node.js / React Native
