import { Steps } from "nextra/components";

安装和配置 Lynx。

<Steps>

  ### 创建项目

  [Lynx](https://lynxjs.org/) 文档

  ### 添加 Canyon 和配置

  > [!TIP]
  >
  > Lynx 编译器默认使用 SWC。插件配置相关[文档](https://lynxjs.org/zh/api/rspeedy/rspeedy.tools.swc.html#toolsswc-property)


  ```sh npm2yarn copy
  npm install swc-plugin-coverage-instrument swc-plugin-canyon -D
  ```

  ### 配置 SWC 插件

  ```js filename="lynx.config.ts" {19,20} copy
  import { defineConfig } from '@lynx-js/rspeedy'
  import { pluginQRCode } from '@lynx-js/qrcode-rsbuild-plugin'
  import { pluginReactLynx } from '@lynx-js/react-rsbuild-plugin'

  export default defineConfig({
    plugins: [
      pluginQRCode({
        schema(url) {
          return `${url}?fullscreen=true`
        },
      }),
      pluginReactLynx(),
    ],
    tools:{
      swc:{
        jsc:{
          experimental:{
            plugins:[
                ['swc-plugin-coverage-instrument',{}],
                ['swc-plugin-canyon',{}]
            ]
          }
        }
      }
    }
  })

  ```

  ### 完成了
  继续查看[首次获取覆盖率数据 - 验证](/docs/getting-started/first-coverage#%E6%A3%80%E6%9F%A5)。
